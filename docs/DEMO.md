# Demo runbook

Target length: 5–6 minutes. Use a fresh ChatGPT Work chat with the production plugin refreshed.

## Setup

1. Ask: **“Get me started.”**
2. Choose **See demo**. This loads only deterministic public-safe data.
3. Open the dashboard and keep the Today tab visible before presenting.

## Story

1. **The premise — 30 seconds**
   - “Software changes. Careers do too. Self-Deprecation turns that ongoing migration into a practical weekly system.”
   - Point to the restrained status joke, then move directly to utility.
2. **Today — 45 seconds**
   - Run the daily brief.
   - Show the next useful actions across job matches, people, events, and learning.
   - If scoring is partial, use **Continue scoring** once and show the progress update.
3. **Jobs + Decisions API — 75 seconds**
   - Search for matching remote AI/product engineering roles.
   - Show fit score, concrete reason chips, source attribution, and save one role.
   - Say: “The Decisions API ranks jobs against my criteria; if it times out, the same flow falls back to deterministic scoring.”
4. **Learning journal — 60 seconds**
   - Open the seeded presentation note.
   - Search for “evals,” then save one short takeaway or follow-up question.
   - Say: “The useful part of a conference talk should still be findable six months later.”
5. **People, Prep, Events, and News — 75 seconds**
   - Open the saved contact and add a contextual note.
   - Open interview prep for the saved job.
   - Show the local event and current AI news with source links.
6. **AI-native growth — 45 seconds**
   - Complete the Level assessment and show the next small quests.
   - Say: “This is not a graduation badge. It is a repeatable way to decide what to practice next.”
7. **Close — 30 seconds**
   - Return to Today.
   - “The product is one connected loop: notice change, choose the next move, record what worked, and repeat.”

## Failure-path proof

- Source unavailable: show the source status without blocking other results.
- Decisions unavailable: show heuristic scoring and the fallback label.
- Missing criteria: show conversational onboarding instead of an empty Jobs screen.
- Partial scoring: show explicit continuation; never imply background work that is not running.

## Before going on stage

- Refresh the plugin connection and start a new chat.
- Confirm `ping`, **See demo**, Today, Jobs, Journal, and Level render.
- Confirm production smoke, migrations, and remote secrets are green.
- Keep one screenshot of each main state available in case venue networking fails.
